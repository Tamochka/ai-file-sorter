# AI File Sorter

Безопасное настольное приложение для сортировки файлов с локальным ИИ. Оно сначала строит редактируемый план, а перемещает файлы только после явного подтверждения.

![Лицензия MIT](https://img.shields.io/badge/license-MIT-1769aa.svg)

## Возможности

- Работает на macOS и Windows через Tauri 2.
- Подключается к LM Studio, Ollama или любому OpenAI-совместимому API.
- Автоматически подставляет активную модель LM Studio; список моделей можно обновить вручную.
- Отправляет модели текст только из поддерживаемых текстовых форматов. Для остальных файлов передаёт метаданные: путь, расширение, размер и даты.
- Выполняет анализ пакетами по 10 файлов: ошибка одного пакета не останавливает следующие.
- Не замораживает окно во время анализа, показывает прогресс каждого прохода и позволяет отменить операцию.
- Прерывает зависший пакет через 90 секунд, даже если ИИ-сервер оставил соединение открытым.
- Один раз повторяет файлы без решения ИИ; после второй неудачи направляет их в `AI Sorted/Не обработано ИИ/...` с сохранением типа, даты и исходной вложенности.
- Показывает статус ИИ для каждой строки, техническую причину сбоя и красную плашку для необработанных файлов.
- Использует стандартные категории: Работа, Личное, Финансы, Учёба, Медиа, Архив, Загрузчики и Прочее.
- Не анализирует повторно `AI Sorted`, внутренности `.app` и системные файлы macOS.
- Не перезаписывает файлы: при конфликте добавляет суффикс `(2)`, `(3)` и т. д.
- Позволяет изменить или исключить любую строку до применения плана, а затем отменить последнюю сортировку.

## Быстрый старт

Нужны Node.js 20+ и Rust. Затем:

```bash
npm install
npm run tauri dev
```

В LM Studio загрузите нужную модель и включите локальный сервер. Приложение само обнаружит активную модель. Для Ollama выберите соответствующий профиль — используется адрес `http://127.0.0.1:11434`.

## Сборка

```bash
npm run tauri build
```

Готовые файлы появятся в `src-tauri/target/release/bundle/`.

## Конфиденциальность

При работе с LM Studio или Ollama данные остаются на компьютере. Перед отправкой данных на внешний OpenAI-совместимый сервис приложение требует отдельного подтверждения. API-ключ не записывается в журнал операций и не выводится в лог.

## Ограничения первой версии

Содержимое PDF, Office-документов, изображений, аудио и видео пока не извлекается локально. В таких случаях ИИ получает только доступные метаданные файла. Перед применением всегда проверяйте предложенный план.
