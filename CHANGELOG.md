# История изменений

## 0.2.1 — 2026-08-13

### Исправлено

- Анализ больше не блокирует окно приложения во время ожидания ответа локальной модели.
- Каждый ИИ-пакет ограничен жёстким тайм-аутом в 90 секунд, который срабатывает даже если сетевой сервер держит соединение открытым бесконечно.
- Проверка подключения и загрузка списка моделей также выполняются асинхронно и не замораживают интерфейс.

### Добавлено

- Живой прогресс основного и повторного проходов: текущий пакет, число обработанных файлов и число файлов без решения.
- Кнопка отмены анализа; отмена не перемещает файлы и не оставляет приложение в занятом состоянии.
- Интеграционный тест с намеренно зависшим HTTP-сервером и отдельный тест отмены запроса.

## 0.2.0 — 2026-08-12

### Добавлено

- Независимая обработка пакетов по 10 файлов: сбой одного запроса больше не останавливает весь анализ.
- Один повторный проход только для файлов, по которым ИИ не вернул решение.
- Категория `Не обработано ИИ` после двух неудачных попыток с сохранением типа файла, даты и исходной вложенности.
- Статусы ИИ, итоговые счётчики и красное выделение необработанных строк в предпросмотре.
- Технические причины для тайм-аутов, невалидного JSON и частичных ответов модели.
- Исправлена отмена последней сортировки для абсолютных путей, сохранённых в журнале операции.

### Сохранено

- Редактируемый план и явное подтверждение перед перемещением.
- Защита от выхода за пределы выбранной папки, разрешение конфликтов имён, отмена операции и исключение `AI Sorted` из повторного сканирования.
