# История изменений

## 0.2.3 — 2026-08-16

### Исправлено

- Режим без общего лимита больше не читает текстовые файлы целиком и не отправляет бесконечный контекст модели.
- Каждый ИИ-запрос ограничен одновременно числом файлов (до 10) и обезличенным размером контекста (до 8 КБ); большой пакет автоматически разбивается на меньшие.
- Из одного текстового файла в запрос может попасть максимум 3 000 символов; ограничение явно показано в интерфейсе.
- Ответ модели ограничен 1 024 токенами, что предотвращает переполнение небольшого контекстного окна при сортировке.
- Профиль Ollama использует совместимый с OpenAI путь `/v1/chat/completions` и корректную проверку доступности сервиса.
- Для HTTP-ошибок API отображается безопасная полезная причина: переполнен контекст, слишком большой запрос, не найдена модель или отклонена авторизация. Тело ответа, пути и содержимое файлов не выводятся.
- Диагностический лог показывает размер контекста каждого пакета без раскрытия имён, путей или содержимого файлов.

## 0.2.2 — 2026-08-15

### Добавлено

- Обезличенный диагностический лог в реальном времени для каждого основного и повторного пакета.
- Для пакета показываются время, номер попытки, длительность, количество файлов, сводка расширений, результат и число файлов без решения.
- Отдельные живые счётчики для файлов, ещё не отправленных модели, и файлов, ожидающих повторной попытки.
- Автоматическая проверка и сборка Windows x64 с NSIS-установщиком и SHA-256.
- Windows-ресурс `icon.ico`, необходимый для EXE и установщика.
- Проверка GUI-подсистемы Windows, чтобы приложение запускалось без лишнего консольного окна.

### Исправлено

- Сортировка проверяет доступность выбранной папки для записи до первого перемещения.
- При ошибке одного из переносов уже перемещённые файлы автоматически возвращаются; журнал отмены записывается только после успешного завершения всей операции.
- Частичная ошибка отмены сортировки также запускает обратный откат и сохраняет журнал для повторной попытки.
- Абсолютные пути из журнала корректно проверяются в Windows, включая префикс диска.
- Категории и редактируемые целевые пути учитывают зарезервированные имена Windows, управляющие символы, точки и пробелы в конце.
- Коллизии целевых путей внутри одного плана определяются без учёта регистра.
- Из анализа исключены `$RECYCLE.BIN`, `System Volume Information`, `Thumbs.db` и `desktop.ini`.
- Внутренний журнал отмены и его временные файлы исключены из анализа и никогда не передаются модели.
- Локальный адрес определяется по настоящему имени узла URL; строка `localhost` в пути или параметрах внешнего адреса больше не обходит подтверждение облачной передачи.
- Vite и React-плагин сборщика обновлены до безопасных веток без известных npm-уязвимостей.
- Для окна Tauri включена ограничивающая Content Security Policy вместо отключённой защиты.

### Конфиденциальность

- В диагностический лог больше не попадают путь выбранной папки, имена недоступных файлов и адрес API.
- Причины сетевых и HTTP-сбоев очищаются от URL и локальных путей, но сохраняют полезный тип ошибки и детали JSON.
- Повторные сообщения о пакетных сбоях не дублируются после завершения анализа.

## 0.2.1 — 2026-08-13

### Исправлено

- Анализ больше не блокирует окно приложения во время ожидания ответа локальной модели.
- Каждый ИИ-пакет ограничен жёстким тайм-аутом в 90 секунд, который срабатывает даже если сетевой сервер держит соединение открытым бесконечно.
- Проверка подключения и загрузка списка моделей также выполняются асинхронно и не замораживают интерфейс.

### Добавлено

- Живой прогресс основного и повторного проходов: текущий пакет, число обработанных файлов и число файлов без решения.
- Кнопка отмены анализа; отмена не перемещает файлы и не оставляет приложение в занятом состоянии.
- Интеграционный тест с намеренно зависшим HTTP-сервером и отдельный тест отмены запроса.

## 0.2.0 — 2026-08-12

### Добавлено

- Независимая обработка пакетов по 10 файлов: сбой одного запроса больше не останавливает весь анализ.
- Один повторный проход только для файлов, по которым ИИ не вернул решение.
- Категория `Не обработано ИИ` после двух неудачных попыток с сохранением типа файла, даты и исходной вложенности.
- Статусы ИИ, итоговые счётчики и красное выделение необработанных строк в предпросмотре.
- Технические причины для тайм-аутов, невалидного JSON и частичных ответов модели.
- Исправлена отмена последней сортировки для абсолютных путей, сохранённых в журнале операции.

### Сохранено

- Редактируемый план и явное подтверждение перед перемещением.
- Защита от выхода за пределы выбранной папки, разрешение конфликтов имён, отмена операции и исключение `AI Sorted` из повторного сканирования.
